# RACE AUTHORITY
*The only racing management game where YOU are Race Control.*

## Run it
- **Browser**: open `index.html` (Chrome/Edge recommended)
- **Windows (Electron)**: `cd electron && npm i electron && npm start`
  - **F11 / Alt+Enter** toggles fullscreen (windowed by default)

## Modes
- **RACE CONTROL (IMA)** — deploy SC/VSC, red flags with standing/rolling restart choice, penalties,
  disqualifications, cost cap setting & breach tribunals, engine dev bans + EDT tokens, regulation votes
  you can honour / force / veto, device legality rulings.
- **TEAM PRINCIPAL** — strategy (ERS, fuel, tyres, rear-gunner), playable Q1/Q2/Q3 qualifying, launch control,
  full driver & sponsor market with clauses, multi-week negotiations with agent counters & hijacks,
  engine supplier switching or become a works manufacturer, academy, star staff poaching, board targets & sackings.
- **SPECTATE** — TV-director broadcast with sound.

## Customise
✏ EDIT NAMES on the main menu — every team, driver, and track name is editable, everywhere, in every mode.
3 save slots · adjustable races per season · points presets · reversed grids · scenario mode.

Season archive: hub → ARCHIVE & BOARD → VIEW PAST SEASONS. Game starts in 2026.
